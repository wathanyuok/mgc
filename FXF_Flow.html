ปุ่มลงบัญชี 2 ปุ่ม — กดได้ตอนไหน

ปุ่มอยู่แท็บกดตอนไหนเงื่อนไขที่ต้องครบลง JE
ลงบัญชีมูลค่ายุติธรรม (Fair Value) Fair Value ทุกสิ้นเดือน ระหว่างสัญญายังไม่ครบ (ตีราคา MTM) 1) Save + อนุมัติแล้ว (Active/Approved)
2) กรอก Spot Rate สิ้นงวด
3) Spot ≠ Forward (มีผลต่าง)
4) งวดนั้นยังไม่เคยลง		 กำไร: Dr สินทรัพย์ FXF / Cr FX Gain
ขาดทุน: Dr FX Loss / Cr หนี้สิน FXF
ลงบัญชีค่าธรรมเนียม (Fee) Fee Payment เมื่อมีค่าธรรมเนียมจริง (spot fee / ยกเลิก-แก้สัญญา) — ไม่ผูกสิ้นเดือน 1) Save + อนุมัติแล้ว (Active/Approved)
2) ค่าธรรมเนียมรวม > 0
3) ยังไม่เคยลง		 Dr Fee Expense / Cr Bank
สรุปให้เข้าใจง่าย:
• ลงบัญชีมูลค่ายุติธรรม = ปุ่ม "หลัก" ทำทุกสิ้นเดือน เพื่อตีราคากำไร/ขาดทุนตามตลาด (unrealized) → สัญญาต้อง Active + กรอก Spot สิ้นงวดก่อน
• ลงบัญชีค่าธรรมเนียม = ปุ่ม "เสริม" ทำเมื่อมีค่าธรรมเนียมเกิดขึ้นเท่านั้น (บางสัญญาไม่มีเลย = ไม่ต้องกด) → ต้องกรอกค่าธรรมเนียม > 0 ก่อน
• ตอนนี้ทั้ง 2 ปุ่มเทาเพราะ FXF ยังเป็น Draft + ยังไม่กรอก Spot/ค่าธรรมเนียม → ต้องอนุมัติให้ Active + กรอกค่าก่อน
